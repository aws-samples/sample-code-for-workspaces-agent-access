# Task: Open Notepad and Create a Text File

Open Notepad, type a short message, and save it to the Desktop.

## Steps

1. Press the Windows key to open the Start Menu
2. Type "notepad" and click the Notepad result
3. Wait for Notepad to open
4. Type the following text:
   ```
   Hello from the Generic Computer-Use Agent.
   This file was created automatically.
   ```
5. Press Ctrl+S to save
6. In the Save As dialog, navigate to the Desktop
7. Set the filename to "agent-test.txt"
8. Click Save
9. Close Notepad with Alt+F4

## Verification

Take a screenshot after saving to confirm the file was created successfully.
